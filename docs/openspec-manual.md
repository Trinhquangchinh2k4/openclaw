# OpenSpec Manual Fallback

`openspec` CLI was not found in PATH during policy installation.

Do not install packages with `apt` or `curl` without explicit approval.

Until OpenSpec CLI is available, record spec changes manually under `docs/specs/` or the relevant project docs with:

- Problem
- Proposed behavior
- Acceptance criteria
- Non-goals
- Migration/rollback
- Evidence plan

Every implementation still needs a spec reference in task/evidence reports.
