# Superpowers Workflows

No dedicated Superpowers package or instruction set was found in this workspace. Use this minimum workflow set until a richer skill is installed.

## Brainstorm

Explore options, constraints, risks, and tradeoffs before committing to implementation.

## Design Sign-Off

For `YELLOW` or `RED` work, state the design, affected files/services, migration path, rollback, and evidence plan before production-impacting changes.

## Plan

Break the work into spec, task/bead, implementation steps, validation, evidence, and review.

## TDD

Where practical, write or identify tests before implementation. For existing systems, preserve behavior with regression checks.

## Debugging

Use reproducible evidence: logs, commands, failing tests, service status, and minimal hypotheses.

## Review

Review for bugs, regressions, missing tests, secrets, unrelated edits, production risk, and rollback.

## Evidence Report

Every completion needs evidence: commands run, tests run, logs checked, UI/API checked, diff summary, edge cases, and rollback plan.
